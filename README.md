## Workshop Outline

During this workshop, you will learn:

- Introduction to Move on Sui (Hello Move)
- Move Object Model & Upgradeable Concepts
- Working with Walrus
- Building DeFi on Sui using **DeepBook V3**

This is a **hands-on session**, so please complete the preparation below before attending.
